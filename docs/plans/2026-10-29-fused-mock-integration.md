# Fused 모의 위치 연동과 Note8 검증

작성일: 2026-10-29 (Asia/Seoul)

## 승인된 변경과 보존 범위

사용자는 포크 앱에 Fused 연동을 추가하고 노트8에서 위치 왕복이 사라지는지 검증하도록 지시했다. 이 지시는 원본의 Play services 미사용 제약에 대한 위치 동기화 목적의 예외를 승인한다. 지도는 MapLibre를 유지하며 계정·Firebase·위치 전송 기능은 추가하지 않는다.

기존 `/Users/han-byeol/Work/gps-mock`과 노트8에 설치된 원본 앱의 데이터는 보존한다. 원본 APK의 서명을 확인하고, 다른 서명의 앱을 설치하기 위해 원본을 삭제하지 않는다. 별도 앱 ID를 가진 테스트 빌드를 함께 설치해 검증한다. 모의 위치 앱 선택은 테스트 빌드에 맞게 전환하고 변경 내역을 검증 기록에 남긴다.

debug 빌드는 `com.locationjoystick.app.fork`, 표시 이름은 `locationjoystick Fused`, 버전 접미사는 `-fused-fork`다. release 앱 ID는 유지한다.

기준 증거는 [Note8 조사 기록](../research/2026-10-29-note8-location-snapback.md)이다. Android 9(API 28)의 원본 v0.16.0에서 GPS 갱신은 유지되는데 Fused가 약 1.3km 떨어진 네트워크 계열 위치로 갔다가 다음 스냅샷에서 복귀했다. 자체 지도만 보아서는 이 시스템 출력 차이를 검증할 수 없다.

## 구현 순서

1. Google Fused API를 감싼 어댑터와 모의 세션 수명 관리를 추가한다. 활성화 성공 이후에만 위치를 쓰고, 요청 순서·중단·재시작·실패 정리를 테스트한다.
2. 서비스가 한 번 만든 fix를 GPS·network·사용 가능한 Fused에 같은 좌표와 시각으로 전달하게 한다. 일시정지와 화면 꺼짐 중에도 주입을 유지한다.
3. Play services가 없는 환경은 명시적인 로그와 GPS/network 경로를 유지한다. 사용 가능한 Fused의 권한·API 오류는 정상 동작으로 표시하지 않고 세션을 실패 처리한다.
4. 정상 중지·park·오류·종료에서 이전 세션의 대기 쓰기를 무효화하고 Fused mock mode와 등록한 공급자를 정리한다. 제한 시간과 취소를 처리하며 Android mock 표시는 유지한다.
5. 관련 기술 제약·엔진 설명·사용자 문제 해결 문서를 코드와 함께 갱신한다.

## 자동 검증

- Fused 활성화 성공 전 쓰기 금지, 활성화 실패·취소 후 정리, 중지와 쓰기의 순서, 이전 세션 쓰기 거부, 재시작, API timeout을 검사한다.
- GPS/network가 같은 fix를 받고 정상 종료 시 등록 공급자를 제거하는지 확인한다.
- `make format`, `make lint`, `make test`, debug APK 빌드를 실행한다. 이미 알려진 시간 의존 테스트의 최초 실패와 재실행 결과도 숨기지 않는다.

## Note8 검증과 판정

설정 비교가 재현 조건을 바꾸지 않도록 먼저 기존 위치 정확도·검색 설정을 유지한다. 설치 버전, APK 서명, 선택된 모의 앱, 권한, PID와 모드를 기록한다. 실기기 결과는 별도 증거 문서에 남기며 이 계획만으로 통과를 주장하지 않는다.

| 조건 | 계획한 관찰 | 필요한 증거 |
|---|---|---|
| 고정 모의 위치 | 최소 90초 | GPS/network/Fused 좌표 차이와 fix 시각, 서비스 유지 |
| 경로 재생 | 최소 120초 | 경로 진행에 맞는 세 공급자의 연속 위치, 실제 위치 계열 급변 없음 |
| 경로 일시정지 | 최소 30초 | 좌표는 고정되고 fix 시각은 계속 갱신 |
| 화면 꺼짐 | 최소 120초 | 화면 OFF 기록, 갱신 유지, 서비스·wake lock 상태 |
| 정상 중지 | 중지 직후와 이후 | Fused mock mode 해제, 등록 공급자 제거, 새 실제 위치 수신 또는 미수신 사유 |

수집 간격과 실제 관찰 시간을 결과에 적는다. 계획보다 짧거나 측정하지 못한 조건은 미검증으로 남긴다. GPS와 Fused가 다른 시점의 이동 중 fix를 갖는 경우는 나이·속도를 고려해 거리 차이를 해석한다. mock 표시는 탐지 우회 대상이 아니며 실제 위치가 섞이는지와 별개로 유지한다.

관찰 구간에서 튐이 없었다는 결과를 모든 기기·모든 시간의 보장으로 확대하지 않는다. 문제가 재발하면 원시 스냅샷과 시각을 보존하고 해당 공급자 경로를 다시 좁힌다.

## 현재 진행 상태

구현과 APK 설치를 완료했다. 자동 실기기 시험은 고정 위치 단계에서 실제 모드가 `ROUTE_REPLAY`로 바뀌어 계획한 조건을 유지하지 못했고, 전체 안정성 판정은 하지 않았다. 사용자가 직접 확인하겠다고 요청해 추가 자동 조작을 중단했다. 상세 결과와 미검증 범위는 [수정 검증 기록](../research/2026-10-29-fused-fix-verification.md)에 남긴다.
