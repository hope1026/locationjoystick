# 한국어·영어 선택과 한국어 번역 검증

검증일: 2026-10-29 (Asia/Seoul)

## 변경 내용

- 설정 첫 화면에 `App language` / `앱 언어` 항목을 추가했다. 선택 창에서 `한국어`, `English`, 기존 중국어 두 종류와 시스템 기본값을 선택한다.
- 앱·공통 UI·지도·경로·즐겨찾기·설정·온보딩·그룹·위젯·알림 등의 한국어 리소스를 추가했다. 새 지도 지점 편집 화면도 포함한다.
- `AppLanguage.KOREAN`은 `ko`를 사용하며 `ko-KR`도 한국어 선택으로 인식한다. 영어는 기존 기본 리소스를 사용한다.
- 언어 이름은 다른 언어로 전환해도 찾을 수 있도록 각 언어의 고유 표기를 사용한다.
- Android 13 이상은 플랫폼의 앱별 언어 적용을 사용하고, 기존 Android 9–12 경로는 SharedPreferences와 Activity 재생성을 유지한다.
- 경로 목록의 지점 개수와 재생 완료 문구도 번역 가능한 리소스로 바꿨다. 신호 휴지 옵션의 설명은 위치 갱신이 계속되는 현재 구현에 맞췄다.

에뮬레이터는 `gps_mock_api36`, `sdk_gphone64_arm64`, 1080×2400이며 패키지는 `com.locationjoystick.app.fork`다.

새 언어 UI 테스트는 설정에서 한국어 선택 후 한국어 설정·메뉴·경로 편집 리소스를 확인하고, 영어로 다시 바꾸는 흐름을 실행했다. 한국어 상태에서 Activity를 재생성해도 선택과 한국어 화면이 유지되는 것도 확인했다. 기존 설정 및 지점 지도 편집 테스트도 함께 실행했다.

수동 화면 검사에서 한국어 문구·입력 필드·버튼 렌더링과 플랫폼 앱 언어 `[ko]`를 확인했다. 사용자의 미저장 설정이 있어, 강제 종료·재실행 검사는 진행하지 않고 입력값을 보존했다. 아래 이미지는 한국어로 표시된 설정 하위 화면이다.
