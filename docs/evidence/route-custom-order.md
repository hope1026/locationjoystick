# 저장된 경로의 사용자 지정 정렬 검증

검증일: 2026-10-29 (Asia/Seoul)

## 구현 동작

저장된 경로 목록의 정렬 메뉴에 사용자 지정을 추가했다. 이 모드에서 왼쪽 핸들을 길게 누르고 위아래로 드래그한 뒤 놓으면 순서를 저장한다. 이름순·저장일순으로 전환해도 기존 사용자 순서는 유지된다. 검색 중에는 핸들을 비활성화하고 검색을 지우라는 안내를 표시한다.

순서는 경로 ID 목록으로 DataStore에 저장한다. 경로 이름·좌표·지점 순서·재생 옵션을 수정하지 않는다. 새 경로는 기존 사용자 순서 뒤에 붙고, 삭제된 ID와 중복 ID는 표시에서 제외한다. 다음 순서 저장에서는 현재 경로 ID로 정리한다.

지도·위젯의 경로 선택 목록에도 같은 순서를 적용한다. 드래그 편집은 저장된 경로 목록에서 제공한다. 즐겨찾기의 기존 네 가지 정렬은 유지한다. 백업의 선택적 `customRouteOrder` 필드와 가져오기·초기화 처리도 추가했다.

## 자동 검사

- 모델·DataStore·공유 지도 상태·백업 codec·설정 저장·경로 ViewModel의 순서 보존 및 오류 회귀 테스트 통과.
- 실제 DataStore 파일을 닫았다가 다시 열어 사용자 순서와 정렬 모드가 유지되는지 검사했다.
- debug 앱·AndroidTest APK 빌드, 포맷·lint·전체 단위 테스트 통과.
- JVM 테스트 XML 합계: 1,696건, 실패·오류·skip 0건.

## 프로세스 재시작 확인

검증용 별도 AVD `locationjoystick_sort_api36`(API 36, 1080×2400, `emulator-5556`)를 사용했다. 기존 `emulator-5554`의 앱·입력 중 설정은 변경하지 않았다.

일반 앱 프로세스에서 실제 저장된 두 경로를 만들고 ADB의 `input draganddrop`으로 핸들을 이동했다. 앱을 강제 종료한 뒤 다시 실행해 같은 사용자 순서와 핸들이 복원되는지 확인했다.
